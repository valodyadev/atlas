# iOS rules

Loaded on demand when a file under `ios/` is read or edited.

## Gates

```
cd ios/Packages/AtlasKit && swift test -Xswiftc -warnings-as-errors
cd ios && swiftformat --lint .
```

Run `make ios-project` after adding or removing a file: `ios/Atlas.xcodeproj`
is generated by XcodeGen from `ios/project.yml` and is not committed.

## Non-negotiable

- Layering is compiler-enforced: `AtlasCore` <- `AtlasNetworking` /
  `AtlasDesignSystem` <- `AtlasFeature*`. A feature importing another feature
  is a compile error and must stay one. Shared behaviour moves down a layer,
  never sideways.
- `contracts/openapi/v1.json` is read-only here. If the API must change, that
  is a backend change.
- Swift 6 language mode. A shared mutable `static var` will not compile; put
  the state in one `@unchecked Sendable` box with a lock and justify it.
- Package targets declare `macOS` alongside `iOS` so the suite runs on a bare
  toolchain. UIKit-only code belongs in `ios/App` or behind `#if os(iOS)`.
- No third-party SPM dependency without an ADR (ADR 0007).
- `AtlasLog`, never `print`. Design tokens (`Atlas.Spacing.lg`), never literals.
  Dynamic Type always, never fixed point sizes.

## Already-paid-for mistakes

- Use `Date.ISO8601FormatStyle`, not `ISO8601DateFormatter`: the latter is not
  `Sendable`, and Foundation's `.iso8601` decoder rejects the fractional
  seconds ASP.NET Core emits. `AtlasJSON` handles both and is tested against
  real .NET payloads.
- With typed `throws(APIError)`, `catch let error as APIError` is a warning —
  and warnings are errors.
- A `ViewState` needs distinct `empty` and `failed` cases. Conflating `empty`
  with `loaded([])` ships a blank screen.

## Limitation

SwiftLint needs `sourcekitdInProc.framework`, which ships only with a full
Xcode install. Xcode 27.2 is installed here, so it runs and the config is
clean. Two caveats: `brew install swiftlint` fails on macOS 27 (Homebrew
pre-release Tier 2), so use the official `portable_swiftlint.zip`; and the iOS
simulator has no runtimes installed, so simulator and app-target builds still
cannot run (Xcode > Settings > Components).
